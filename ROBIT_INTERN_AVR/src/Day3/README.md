# 3. I2C 통신 (SCL, SDA)

## 3-1. I2C의 정의

I2C(Inter-Integrated Circuit)는 Philips(현재 NXP)에서 개발한 직렬 통신 방식으로, 두 개의 신호선만을 이용하여 여러 장치와 통신할 수 있는 프로토콜이다.

ATmega128에서는 TWI(Two Wire Interface)라는 이름으로 I2C 기능을 제공한다.

## 3-2. SCL과 SDA

| 신호선 | 역할 |
| :--- | :--- |
| **SCL (Serial Clock)** | 마스터가 생성하는 클럭 신호 |
| **SDA (Serial Data)** | 송수신 데이터가 전달되는 신호선 |

SCL은 데이터의 전송 타이밍을 결정하며, SDA는 실제 데이터를 송수신하는 역할을 수행한다.

## 3-3. 동작 원리

I2C 통신은 **Master**와 **Slave** 구조로 이루어진다.

동작 과정은 다음과 같다.

1. Master가 START 신호 생성
2. Slave 주소 전송
3. Slave가 ACK 신호 응답
4. 데이터 송수신
5. STOP 신호 생성

SCL이 HIGH인 동안 SDA가 변화하면 START 또는 STOP 조건으로 인식되며, 데이터는 SCL의 클럭에 맞추어 전송된다.

## 3-4. ATmega128에서의 사용법

ATmega128은 내부에 TWI 모듈을 제공한다.

주로 사용하는 레지스터는 다음과 같다.

| 레지스터 | 기능 |
| :--- | :--- |
| **TWBR** | 통신 속도(Baud Rate) 설정 |
| **TWSR** | 상태(Status) 확인 |
| **TWCR** | TWI 제어 |
| **TWDR** | 데이터 송수신 |
| **TWAR** | 자신의 Slave 주소 설정 |

일반적인 사용 순서는 다음과 같다.

1. TWBR로 클럭 속도 설정
2. START 조건 생성
3. Slave 주소 전송
4. 데이터 송수신
5. STOP 조건 생성

## 3-5. 장점과 단점

| 장점 | 단점 |
| :--- | :--- |
| 배선이 간단하다. | 통신 속도가 SPI보다 느리다. |
| 여러 Slave를 연결할 수 있다. | 장거리 통신에 적합하지 않다. |
| 주소를 이용해 장치를 쉽게 구분할 수 있다. | 데이터 양이 많으면 효율이 떨어진다. |

# 4. UART 통신

UART(Universal Asynchronous Receiver Transmitter)는 클럭 없이 데이터를 송수신하는 비동기 직렬 통신 방식이다.

ATmega128은 UART0과 UART1 두 개의 UART를 제공하며, 동기 모드와 비동기 모드, 전이중 통신(Full-Duplex)을 지원한다.

---

# 5. RS-232와 RS-485

## 5-1. RS-232

RS-232는 가장 오래된 직렬 통신 방식 중 하나이다.

주로 PC와 MCU를 연결하는 데 사용되며, 1:1 통신만 가능하다.

### 장점

- 구현이 간단하다.
- PC와 연결하기 쉽다.
- 디버깅에 많이 사용된다.

### 단점

- 통신 거리가 짧다.
- 노이즈에 약하다.
- 여러 장치를 동시에 연결하기 어렵다.

---

## 5-2. RS-485

RS-485는 차동(Differential) 신호를 이용하는 직렬 통신 방식이다.

D+, D- 두 개의 데이터 라인을 이용하여 통신하며, 장거리에서도 안정적인 통신이 가능하다.

또한 하나의 통신선에 여러 장치를 연결할 수 있어 산업용 제어 시스템과 로봇 분야에서 많이 사용된다.

### 장점

- 장거리 통신 가능
- 노이즈에 매우 강함
- 여러 장치를 하나의 버스로 연결 가능
- 산업용 장비에서 많이 사용

### 단점

- RS-232보다 회로 구성이 복잡하다.
- 송수신 방향 제어가 필요하다.

# 6. RS-232와 RS-485 비교

| 항목 | RS-232 | RS-485 |
| :--- | :---: | :---: |
| 통신 방식 | 1:1 | 1:N |
| 신호 방식 | 단일 신호 | 차동 신호(D+, D-) |
| 최대 통신 거리 | 약 15m | 약 1200m |
| 노이즈 내성 | 낮음 | 높음 |
| 전송 속도 | 보통 | 높음 |
| 산업 현장 사용 | 적음 | 매우 많음 |
| 대표 사용 예 | PC 시리얼 통신 | PLC, 모터, Dynamixel |

# 7. 결론 (Conclusion)

I2C 통신은 두 개의 신호선(SCL, SDA)만을 사용하여 여러 장치와 효율적으로 통신할 수 있는 직렬 통신 방식이며, 배선이 간단하고 다양한 센서를 연결하는 데 적합하다.

UART 통신에서 사용하는 RS-232는 구현이 간단하여 PC와 MCU 간 통신에 적합하지만 통신 거리와 노이즈 내성이 제한적이다. 반면 RS-485는 차동 신호를 이용하여 장거리 및 다중 장치 환경에서도 안정적인 통신이 가능하므로 산업용 장비와 로봇 시스템에서 널리 사용된다.
