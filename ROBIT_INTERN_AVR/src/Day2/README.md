Day 2 과제

ATmega128 ADC 데이터시트 학습 보고서

1. ADC란?

ADC는 Analog-to-Digital Converter의 약자로, 아날로그 신호를 디지털 값으로 변환하는 장치이다.

온도 센서, 조도 센서, 가변저항 등의 출력은 전압이 연속적으로 변하는 아날로그 신호이다. 하지만 마이크로컨트롤러는 이런 전압을 그대로 계산할 수 없기 때문에 ADC를 이용해 정수 형태의 값으로 바꿔야 한다.

ATmega128에는 10비트 ADC가 들어 있다. 10비트로 표현할 수 있는 경우의 수는 2의 10제곱인 1024개이므로, ADC 변환 결과는 0부터 1023까지 나온다. 예를 들어 기준 전압을 5V로 설정했다면 0V에 가까울 때는 0이 나오고, 5V에 가까워질수록 1023에 가까운 값이 나온다.

2. ATmega128 ADC의 특징

ATmega128은 ADC0부터 ADC7까지 총 8개의 단일 입력 채널을 가지고 있다. ADC 입력은 PORTF의 PF0부터 PF7까지 사용할 수 있다.

ADC는 한 번만 값을 측정하는 단일 변환 모드와 계속해서 값을 측정하는 프리 러닝 모드를 지원한다. 변환이 끝났을 때 인터럽트를 발생시키는 기능도 사용할 수 있다.

ADC 변환 결과는 왼쪽 또는 오른쪽으로 정렬할 수 있으며, 기준 전압은 외부 AREF 전압, AVCC 전압 또는 내부 2.56V 전압 중에서 선택할 수 있다. 차동 입력과 증폭 기능도 지원하며, 잡음의 영향을 줄이기 위한 ADC Noise Reduction 모드도 제공한다.

3. ADC 변환 과정

ATmega128의 ADC는 축차 비교 방식을 사용한다. 입력 전압과 내부에서 만든 전압을 단계적으로 비교하면서 입력 전압에 가장 가까운 디지털 값을 찾는 방식이다.

먼저 여러 ADC 입력 중에서 사용할 채널을 선택하고 기준 전압을 설정한다. 그다음 ADC를 활성화하고 변환을 시작한다. ADC 내부의 Sample and Hold 회로는 변환이 진행되는 동안 입력 전압을 일정하게 유지한다.

변환이 완료되면 10비트 결과가 ADCL과 ADCH 레지스터에 저장된다. 프로그램에서는 이 값을 읽어 전압을 계산하거나 LED와 LCD 출력 등에 사용할 수 있다.

4. ADC 값과 전압 계산

10비트 ADC는 기준 전압의 범위를 1024단계로 나눈다. 기준 전압이 5V라면 한 단계의 전압은 다음과 같다.

1LSB = 5V / 1024

계산 결과 약 0.00488V이며, 이는 약 4.88mV이다. 따라서 입력 전압이 약 4.88mV 변할 때마다 ADC 값이 약 1씩 변한다.

ADC 변환값은 입력 전압에 1024를 곱하고 기준 전압으로 나누어 구할 수 있다.

ADC 변환값 = 입력 전압 × 1024 / 기준 전압

반대로 ADC 값으로 입력 전압을 구할 때는 다음 식을 사용한다.

입력 전압 = ADC 변환값 × 기준 전압 / 1024

기준 전압이 5V이고 입력 전압이 2.5V라면 ADC 변환값은 약 512가 된다. 실제 프로그램에서 ADC 최댓값인 1023을 정확히 5.0V로 표시하려는 경우에는 1024 대신 1023으로 나누기도 한다.

5. ADMUX 레지스터

ADMUX는 ADC의 기준 전압, 결과 정렬 방식, 입력 채널을 선택하는 레지스터이다.

REFS1과 REFS0 비트는 기준 전압을 선택한다. 두 비트가 00이면 외부 AREF 핀으로 들어오는 전압을 사용한다. 01이면 AVCC 전압을 사용하고, 11이면 내부 2.56V 전압을 사용한다.

ADLAR 비트는 변환 결과를 왼쪽에 맞출지 오른쪽에 맞출지 결정한다. 10비트 결과를 모두 사용할 때는 일반적으로 오른쪽 정렬을 사용한다.

MUX4부터 MUX0까지의 비트는 ADC 입력 채널을 선택한다. 00000은 ADC0, 00001은 ADC1을 의미하며 같은 방식으로 ADC7까지 선택할 수 있다.

이번 실습에서는 AVCC를 기준 전압으로 사용하고 PF0에 해당하는 ADC0을 선택하였으므로 ADMUX를 0x40으로 설정하였다.

6. ADCSRA 레지스터

ADCSRA는 ADC의 동작을 제어하는 레지스터이다.

ADEN 비트를 1로 설정하면 ADC가 활성화된다. ADSC 비트를 1로 설정하면 ADC 변환이 시작되고, 변환이 끝나면 하드웨어가 ADSC 비트를 자동으로 0으로 바꾼다. 따라서 프로그램에서는 ADSC 비트가 0이 될 때까지 기다린 후 결과를 읽을 수 있다.

ADFR 비트는 프리 러닝 모드를 설정하며, ADIF는 ADC 변환이 완료되었음을 알려 주는 플래그이다. ADIE를 설정하면 ADC 변환 완료 인터럽트를 사용할 수 있다.

ADPS2, ADPS1, ADPS0 비트는 ADC에 들어가는 클록의 분주비를 결정한다. 이번 실습에서는 세 비트를 모두 1로 설정하여 128분주를 사용하였다. ADC를 활성화하고 128분주를 설정한 ADCSRA 값은 0x87이다.

7. ADC 클록과 변환 시간

ATmega128에서 10비트 정확도를 얻기 위해 권장되는 ADC 클록은 일반적으로 50kHz에서 200kHz 사이이다.

사용한 MCU의 CPU 클록은 16MHz이며 분주비는 128이다. 따라서 ADC 클록은 16MHz를 128로 나눈 125kHz가 된다. 125kHz는 권장 범위 안에 있으므로 10비트 ADC 변환에 적합하다.

일반적인 ADC 변환에는 13번의 ADC 클록이 필요하다. ADC 클록이 125kHz일 때 한 번의 변환에는 약 104마이크로초가 걸린다. ADC를 처음 활성화한 직후의 첫 번째 변환은 내부 회로를 초기화하는 과정 때문에 일반적인 변환보다 시간이 더 오래 걸릴 수 있다.

8. ADC 변환 결과 읽기

10비트 ADC 결과는 ADCL과 ADCH 레지스터에 나누어 저장된다. ADCL에는 결과의 하위 비트가 저장되고 ADCH에는 상위 비트가 저장된다.

두 레지스터를 따로 읽는 경우에는 ADCL을 먼저 읽고 ADCH를 읽어야 한다. 순서를 지키지 않으면 서로 다른 변환 결과가 섞일 수 있다.

AVR C에서는 ADC라는 이름을 사용하여 ADCL과 ADCH의 값을 한 번에 읽을 수 있다. 이번 실습에서도 변환이 완료될 때까지 기다린 후 ADC 값을 읽는 방법을 사용하였다.

9. 단일 변환 모드와 프리 러닝 모드

단일 변환 모드는 ADSC 비트를 1로 설정할 때마다 ADC가 한 번만 변환하는 방식이다. 새로운 값이 필요할 때마다 프로그램에서 변환을 다시 시작해야 한다. 일정한 간격으로 값을 측정하거나 필요한 순간에만 센서값을 읽을 때 사용할 수 있다.

프리 러닝 모드는 한 번 변환을 시작하면 ADC가 계속해서 새로운 값을 측정하는 방식이다. 이전 변환이 끝나면 다음 변환이 자동으로 시작되기 때문에 센서값을 계속 확인해야 할 때 사용할 수 있다.

이번 가변저항 실습에서는 값을 읽을 때마다 변환을 시작하는 단일 변환 방식을 사용하였다.

10. ADC 입력 회로

가변저항의 양쪽 바깥 단자를 각각 5V와 GND에 연결하고, 가운데 단자를 PF0에 연결하였다. 가변저항을 돌리면 가운데 단자의 전압이 0V에서 5V 사이로 변하고, 이 전압이 ADC0으로 입력된다.

가변저항을 한쪽 끝으로 돌렸을 때 ADC 값은 0에 가까워지고, 반대쪽 끝으로 돌렸을 때는 1023에 가까워졌다. 이를 통해 가변저항의 아날로그 전압이 디지털 값으로 변환되는 것을 직접 확인할 수 있었다.

11. ADC 사용 시 주의사항

ADC는 작은 전압 차이를 구분하기 때문에 전원과 신호선의 잡음에 민감하다.

AVCC는 ADC에 전원을 공급하는 단자이므로 반드시 올바르게 연결해야 한다. 전원 잡음을 줄이기 위해 LC 필터나 커패시터를 사용할 수 있다. AREF에는 기준 전압이 연결되므로 설정한 기준 전압보다 높은 전압이 입력되지 않도록 주의해야 한다.

아날로그 입력선은 가능한 한 짧게 연결하고 빠르게 변하는 디지털 신호선과 떨어뜨리는 것이 좋다. ADC 변환 중에는 주변 I/O 포트의 상태를 불필요하게 변경하지 않는 것이 좋다.

측정값이 계속 흔들린다면 여러 번 측정한 값의 평균을 구하거나 디지털 필터를 사용할 수 있다. 작은 아날로그 신호를 측정할 때는 ADC Noise Reduction 모드를 사용하는 방법도 있다.

기준 전압이나 입력 채널을 변경한 직후의 첫 번째 측정값은 부정확할 수 있으므로, 필요한 경우 첫 번째 결과를 버리고 다시 측정하는 것이 안전하다.
