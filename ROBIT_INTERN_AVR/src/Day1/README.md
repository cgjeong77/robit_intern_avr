Day 1 과제

플로팅(Floating) 상태에 대한 이해

1. 플로팅(Floating) 상태란?

플로팅 상태는 마이크로컨트롤러의 입력 핀이 VCC나 GND에 확실하게 연결되지 않아 입력값이 정해지지 않은 상태이다.

디지털 입력은 HIGH와 LOW 두 가지 상태를 구분한다. HIGH는 논리값 1이고 LOW는 논리값 0이다. 하지만 입력 핀이 아무 곳에도 연결되지 않으면 HIGH인지 LOW인지 확실하지 않게 된다. 이런 상태에서는 주변의 전기적 잡음이나 정전기 등에 따라 입력값이 계속 바뀔 수 있다.

2. 플로팅(Floating) 상태가 발생하는 이유

마이크로컨트롤러의 입력 핀은 입력 임피던스가 높기 때문에 핀으로 흐르는 전류가 매우 작다. 따라서 입력 핀이 VCC나 GND에 연결되지 않으면 핀의 전압을 일정하게 유지하기 어렵다.

예를 들어 스위치를 입력 핀과 GND 사이에 연결하면 스위치를 눌렀을 때는 입력 핀이 GND에 연결되어 LOW가 된다. 하지만 스위치를 누르지 않았을 때 입력 핀이 다른 곳에 연결되어 있지 않으면 플로팅 상태가 된다.

3. 플로팅(Floating) 상태가 문제가 되는 이유

플로팅 상태의 입력 핀은 주변의 잡음, 정전기, 누설 전류 등의 영향을 쉽게 받는다. 이 때문에 실제로 스위치를 누르지 않았는데도 눌린 것으로 인식될 수 있다.

입력값이 HIGH와 LOW 사이에서 불규칙하게 변하면 LED나 모터가 의도하지 않게 작동할 수 있다. 외부 인터럽트를 사용하는 경우에는 스위치를 누르지 않았는데도 인터럽트가 발생할 수 있다. 같은 프로그램을 실행해도 결과가 일정하지 않기 때문에 오류의 원인을 찾기도 어려워진다.

따라서 디지털 입력 핀은 사용하지 않는 상태에서도 HIGH 또는 LOW 중 하나로 값이 정해지도록 회로를 구성해야 한다.

4. 풀업 저항을 이용한 해결 방법

풀업 저항은 입력 핀과 VCC 사이에 저항을 연결하는 방식이다. 스위치를 누르지 않았을 때는 입력 핀이 저항을 통해 VCC와 연결되므로 HIGH 상태를 유지한다. 스위치를 누르면 입력 핀이 GND와 직접 연결되어 LOW 상태가 된다.

풀업 방식에서는 스위치를 누르지 않았을 때 입력값이 1이고, 스위치를 눌렀을 때 입력값이 0이다. 외부 풀업 저항으로는 보통 약 10kΩ의 저항을 사용할 수 있다.

저항 없이 VCC와 GND가 스위치로 직접 연결되면 스위치를 누르는 순간 큰 전류가 흐를 수 있으므로 반드시 저항을 사용해야 한다.

5. 풀다운 저항을 이용한 해결 방법

풀다운 저항은 입력 핀과 GND 사이에 저항을 연결하는 방식이다. 스위치를 누르지 않았을 때는 입력 핀이 저항을 통해 GND와 연결되어 LOW 상태를 유지한다. 스위치를 누르면 입력 핀이 VCC와 연결되어 HIGH 상태가 된다.

풀다운 방식에서는 스위치를 누르지 않았을 때 입력값이 0이고, 스위치를 눌렀을 때 입력값이 1이다. 스위치의 기본 입력값을 LOW로 만들고 싶을 때 사용할 수 있다.

6. ATmega128의 내부 풀업 저항

ATmega128에는 내부 풀업 저항 기능이 들어 있다. 내부 풀업 저항을 사용하면 외부에 별도의 저항을 연결하지 않아도 입력 핀의 플로팅 상태를 막을 수 있다.

PD2 핀을 입력으로 설정하려면 DDRD의 PD2 비트를 0으로 만든다.

DDRD &= ~(1 << PD2);

그다음 PORTD의 PD2 비트를 1로 설정하면 내부 풀업 저항이 활성화된다.

PORTD |= (1 << PD2);

내부 풀업 저항을 사용하면 스위치를 누르지 않았을 때는 HIGH가 입력되고, 스위치를 눌러 GND와 연결했을 때는 LOW가 입력된다.

따라서 다음 조건을 사용하면 PD2에 연결된 스위치가 눌렸는지 확인할 수 있다.

if (!(PIND & (1 << PD2)))

조건 앞에 느낌표가 붙는 이유는 풀업 방식에서 스위치를 눌렀을 때 입력값이 0이 되기 때문이다.

ATmega128은 내부 풀업 저항은 지원하지만 내부 풀다운 저항은 지원하지 않는다. 따라서 풀다운 방식이 필요하면 외부 저항을 직접 연결해야 한다.
